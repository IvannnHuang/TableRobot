# Microduck (TableRobot v3)

A walking biped based on Pollen Robotics' Microduck, run by an ESP32-S3 instead of a Raspberry Pi, with a touch screen + camera head. Planned after the robot dog ([`../robotdog/`](../robotdog/)).

**Status: analysis only.** Findings, servo options and prices, risks, the suggested architecture and the pending decisions are in **[docs/MICRODUCK_PLAN.md](docs/MICRODUCK_PLAN.md)**.
